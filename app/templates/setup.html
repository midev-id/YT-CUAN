  1. {{ '✓' if d.google else '1' }}

    Pasang akses Google

    {% if d.google %}Terpasang (tipe {{ client_type }}){% else %}Belum{% endif %}

    Aplikasi butuh file client_secrets.json supaya boleh mengatur live di YouTube atas nama channel Anda. Cukup sekali untuk semua channel.

    Belum punya filenya? Buat di Google Cloud (±10 menit)
    1. Buka Google Cloud, buat project baru (nama bebas, misalnya YT Live).
    2. Aktifkan YouTube Data API v3 untuk project itu, klik Enable.
    3. Buka OAuth consent screen. Pilih External, isi nama aplikasi dan email Anda. Di bagian Audience → Test users, tambahkan email Google pemilik tiap channel.
    4. Buka Clients → Create client. {% if local %}Pilih tipe Desktop app (dashboard ini dibuka dari komputer sendiri). {% else %}Pilih tipe Web application, lalu di Authorized redirect URIs isi {{ callback }}{% endif %}
    5. Klik Download JSON pada client yang baru dibuat, lalu unggah file itu di atas.

    Selama status aplikasi di Google masih Testing, login berlaku 7 hari. Untuk pemakaian jangka panjang, klik Publish app di halaman Audience.

    Stream key adalah "jalur" pengiriman video ke YouTube. Satu key bisa membawa sampai {{ 3 }} live sekaligus. Disarankan 3 key per channel.

    1. Buka YouTube Studio dengan akun {{ st.ch.title }}, klik Create → Go live.
    2. Pilih tab Stream. Di bagian Stream key, buka pilihan key lalu klik Create new stream key.
    3. Beri nama (misalnya Key 1), pilih Variable, lalu simpan. Ulangi untuk key berikutnya.
    4. Kembali ke sini dan klik tombol di bawah.

    Channel yang belum pernah live harus verifikasi nomor HP dulu, dan YouTube bisa butuh sampai 24 jam sebelum fitur live aktif.
